## Цель
Освоение работы с двумерными массивами 

## Описание
Программа обрабатывает целочисленную матрицу. Сначала она находит строки, которые состоят исключительно из нечетных чисел. Затем для каждой строки вычисляется сумма модулей её элементов, и находится строка с максимальной такой суммой. Исходная матрица выводится на экран, после чего выводятся результаты поиска.

## Исходные данные
Размер матрицы: 3x3
Элементы матрицы:
1 3 5
2 4 6
-1 -3 -5

## Ожидаемые результаты
Программа выводит исходную матрицу, затем номера строк, содержащих только нечетные числа, и строку с максимальной суммой модулей.

Пример вывода программы:
```
Enter number of rows (1-20): 3
Enter number of columns (1-20): 3
Enter element [1][1]: 1
Enter element [1][2]: 3
Enter element [1][3]: 5
Enter element [2][1]: 2
Enter element [2][2]: 4
Enter element [2][3]: 6
Enter element [3][1]: -1
Enter element [3][2]: -3
Enter element [3][3]: -5

Matrix:
1 3 5 
2 4 6 
-1 -3 -5 

Rows with only odd elements:
Row 1, sum of absolute values: 9
Row 3, sum of absolute values: 9
Row with the maximum sum of absolute values: 2, sum: 12
```
